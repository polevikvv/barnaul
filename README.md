# Гид по Барнаулу (учебный проект)

Статическое веб-приложение: HTML, CSS, JavaScript, без сборки.

## Запуск
Откройте `index.html` в браузере (нужен интернет для карты и шрифта).
Для публикации загрузите папку на GitHub Pages, Netlify или Vercel.

## Карта 2ГИС
1. Получите ключ на сайте для разработчиков 2ГИС (dev.2gis.com), проверьте условия и ограничения ключа.
2. Вставьте его в `config.js`: `DGIS_KEY: "ваш_ключ"`.
3. При первом запуске приложение само определит точки для мест без координат через геокодер 2ГИС по адресу и сохранит их в localStorage.

Без ключа работает карта OpenStreetMap, но показываются только места с готовыми координатами (Демидовская площадь, Дом под шпилем, Нагорный парк).

## Данные
`places.js`: 26 мест. Адреса и описания собраны из открытых источников (barnaul.org, tonkosti.ru, Wikipedia, Wikimedia Commons), перепроверьте их перед сдачей.

## Фото
Папка `img/`: 9 снимков из приложения «Барнаул Наследие». Подтвердите права на них, иначе отключите: в `config.js` поставьте `PHOTOS: false`.

## Проверка данных
См. `DATA_CHECK.md`: расхождения в DemoData.kt и список мест, которые ещё не перенесены.
